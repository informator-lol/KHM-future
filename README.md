# Карта Хмельниччини

Неофіційна вебкарта повітряних загроз у Хмельницькій області. Позиції та рух цілей розраховуються за внесеними даними; це не пряме радіолокаційне спостереження.

## Файли

- `index.html` — карта, адмінпанель і створення PNG.
- `about.html` — сторінка «Про сайт» та посилання на Telegram.
- `README.md` — ця інструкція.

## Запуск

Розмістіть `index.html` та `about.html` в одній папці статичного вебхостингу й відкрийте `index.html`. Збірка не потрібна. Для копіювання зображень використовуйте HTTPS; доступ до буфера обміну залежить також від браузера та його дозволів.

Для завантаження бібліотек, плиток карти, синхронізації та даних тривог потрібен інтернет. Відкриття файлу напряму з диска не гарантує роботу авторизації й копіювання PNG.

## Режими роботи

У `index.html` уже міститься конфігурація Firebase. Онлайн-режим використовує Google-вхід і Firestore. Налаштування позначені як `FIREBASE_CONFIG` та `ADMIN_EMAIL`. Для власного розгортання налаштуйте свій проєкт, авторизацію, дозволені домени й правила доступу Firestore. Прихована адмінпанель сама по собі не захищає базу від запису.

Коли Firebase не налаштований або його бібліотека недоступна, код переходить у локальний режим: адміністрування доступне локально, дані зберігаються у браузері. Такий режим не забезпечує спільну онлайн-карту для глядачів.

## Використання

- Натисніть на мітку, щоб переглянути інформацію про ціль.
- В онлайн-режимі кнопка замка відкриває вхід адміністратора.
- Адміністратор може додавати цілі, редагувати маршрути, кількість у групі, статуси та коментарі.
- «Швидкість часу» змінює темп розрахункового руху: ×1 — звичайний час; більші множники прискорюють його.
- Кнопка «Про сайт» відкриває інформаційну сторінку.

## Один скріншот для кількох цілей

1. В адмінпанелі натисніть «Зробити скріншот».
2. Натискайте потрібні мітки на карті. Вибрані мітки отримують блакитну рамку та галочку. Повторне натискання знімає виділення.
3. Натисніть «Створити PNG».
4. Скопіюйте зображення або завантажте PNG.

Кілька цілей об’єднуються в одне зображення з окремими пронумерованими картками. Група вибирається цілком: одна мітка може містити кілька одиниць. На картці групи показуються мініатюри та кількість. Для великих груп відображається до семи мініатюр, а повна кількість указується числом.

«Скасувати» або Escape закриває режим вибору. Якщо відкритий перегляд PNG, Escape спершу закриває його.

## Джерела та обмеження

- Карта: OpenStreetMap; бібліотека відображення: Leaflet.
- Межі районів: дані ОПОРИ.
- Автоматичні тривоги: Tryvoha.online, якщо функція ввімкнена.

Показаний раніше бейдж автоматичних тривог прибраний з верхнього рядка. Функція автоматичних тривог залишається в адмінпанелі.
